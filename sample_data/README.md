# Sample Data

`phantom/` is a **synthetic** CT phantom DICOM series: 8 slices, 512x512,
generated by `tools/make_phantom.py`. It is not real patient or specimen
imaging data -- it is procedurally generated (background air + soft-tissue
body + a bright outer "skin" shell), so there are no privacy, licensing, or
data-ownership concerns with including it in this repository.

Regenerate it (or make a different size/slice count) with:

```bash
python3 tools/make_phantom.py -o sample_data/phantom -n 8
```

To try it in the SKINPEELER GUI: build the project, launch `SKINPEELER`,
and open `sample_data/phantom/` as the DICOM directory to load.
